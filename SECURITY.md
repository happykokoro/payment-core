# Security

Use GitHub's private vulnerability reporting on this repository's Security tab
when available. Otherwise contact the repository owner privately through an
existing channel; do not put secrets or exploitable details in a public issue.

Include the affected commit, reproduction steps, impact and a minimal test case
using test data. Never send wallet keys, production credentials or customer data.

Only the current `main` branch is maintained. This initial release has automated
failure, concurrency and recovery tests but has not received an independent
security audit. See `docs/OPERATIONS.md` for deployment and recovery requirements.
